# Задание 1

## Задача 1.2. Сумма последних цифр

### Текст задачи

Реализовать метод `sumLastNums(int x)`, который возвращает сумму двух
последних цифр переданного целого числа.

### Алгоритм решения

1.  Получить последнюю цифру числа с помощью остатка от деления на 10.
2.  Удалить последнюю цифру целочисленным делением на 10.
3.  Получить последнюю цифру оставшегося числа.
4.  Сложить две полученные цифры и вернуть результат.

Для получения последней цифры используются вспомогательные методы
`lastNum`, а для удаления последней цифры --- `putLastNum`.

## Задача 1.4. Есть ли позитив

### Текст задачи

Реализовать метод `isPositive(int x)`, который возвращает `true`, если
число положительное, и `false` в противном случае.

### Алгоритм решения

Сравнить переданное число с нулём. Если `x > 0`, вернуть `true`. Для
нуля и отрицательных чисел вернуть `false`.

## Задача 1.6. Большая буква

### Текст задачи

Реализовать метод `isUpperCase(char x)`, который возвращает `true`, если
символ является заглавной латинской буквой в диапазоне от `A` до `Z`.

### Алгоритм решения

Проверить, что код символа находится между символами `'A'` и `'Z'`
включительно. Если оба условия выполняются, вернуть `true`, иначе ---
`false`.

## Задача 1.8. Делитель

### Текст задачи

Реализовать метод `isDivisor(int a, int b)`, который возвращает `true`,
если одно из двух чисел делится на другое без остатка.

### Алгоритм решения

Проверить делимость первого числа на второе и второго числа на первое с
помощью оператора `%`. Если хотя бы одна проверка даёт остаток 0,
вернуть `true`. Особый случай --- нулевые значения: перед операцией
остатка необходимо исключить деление на ноль.

## Задача 1.10. Многократный вызов

### Текст задачи

Реализовать метод `lastNumSum(int a, int b)`, который складывает
последние цифры двух чисел. С помощью этого метода последовательно
сложить пять чисел, каждый раз используя предыдущий результат.

### Алгоритм решения

1.  Получить последнюю цифру каждого из двух чисел.
2.  Сложить полученные цифры.
3.  Вывести выполняемое сложение и вернуть сумму.
4.  В главном меню последовательно вызвать метод пять раз, передавая в
    следующий вызов результат предыдущего.

# Задание 2

## Задача 2.2. Безопасное деление

### Текст задачи

Реализовать метод `safeDiv(int x, int y)`, который возвращает результат
деления `x` на `y`. Если делитель равен нулю, метод должен вернуть `0`.

### Алгоритм решения

Сначала проверить, равен ли делитель нулю. Если да - вернуть `0`. В
противном случае привести числитель к типу `double` и выполнить деление,
чтобы получить вещественный результат.

## Задача 2.4. Строка сравнения

### Текст задачи

Реализовать метод `makeDecision(int x, int y)`, который возвращает
строку с двумя числами и соответствующим знаком сравнения: `<`, `>` или
`==`.

### Алгоритм решения

Сравнить два числа: - если `x == y`, сформировать строку со знаком
`==`; - если `x < y`, сформировать строку со знаком `<`; - во всех
остальных случаях сформировать строку со знаком `>`.

Вернуть полученную строку.

## Задача 2.6. Тройная сумма

### Текст задачи

Реализовать метод `sum3(int x, int y, int z)`, который возвращает
`true`, если сумму каких-либо двух из трёх чисел можно приравнять к
третьему.

### Алгоритм решения

Проверить все три возможные комбинации: - `x + y == z`; -
`x + z == y`; - `y + z == x`.

Если хотя бы одно равенство выполняется, вернуть `true`. Иначе вернуть
`false`.

## Задача 2.8. Возраст

### Текст задачи

Реализовать метод `age(int x)`, который возвращает строку с числом и
правильной формой слова: «год», «года» или «лет».

### Алгоритм решения

1.  Получить последнюю цифру числа с помощью `% 10`.
2.  Получить последние две цифры с помощью `% 100`.
3.  Если последние две цифры находятся в диапазоне от 11 до 19 либо
    последняя цифра равна 0 или больше 4, использовать слово «лет».
4.  Если последняя цифра находится в диапазоне от 2 до 4, использовать
    слово «года».
5.  В остальных случаях использовать слово «год».

## Задача 2.10. Вывод дней недели

### Текст задачи

Реализовать метод `printDays(String x)`, который принимает название дня
недели и выводит этот день и все последующие дни до воскресенья. Если
строка не соответствует названию дня недели, вывести сообщение «это не
день недели». Для выбора использовать `switch`.

### Алгоритм решения

Переданное название дня сравнивается с вариантами в операторе `switch`.
Для каждого дня выводится последовательность от выбранного дня до
воскресенья. Если ни один вариант не совпал, выполняется ветка `default`
и выводится сообщение об ошибке.

# Задание 3

## Задача 3.2. Числа наоборот

### Текст задачи

Реализовать метод `reverseListNums(int x)`, который возвращает строку с
числами от `x` до `0` включительно в обратном порядке.

### Алгоритм решения

Создать пустую строку. Организовать цикл от `x` до `0` с шагом `-1`. На
каждой итерации добавлять текущее число в строку. После завершения цикла
вернуть строку.

## Задача 3.4. Степень числа

### Текст задачи

Реализовать метод `pow(int x, int y)`, который возвращает результат
возведения числа `x` в степень `y`.

### Алгоритм решения

Изначально установить результат равным 1. Выполнить цикл `y` раз, на
каждой итерации умножая накопленный результат на `x`. После завершения
цикла вернуть результат.

## Задача 3.6. Одинаковость

### Текст задачи

Реализовать метод `equalNum(int x)`, который возвращает `true`, если все
цифры числа одинаковы, и `false` в противном случае.

### Алгоритм решения

1.  Определить количество цифр числа с помощью вспомогательного метода
    `counterNumbers`.
2.  Если число состоит из одной цифры, вернуть `true`.
3.  Последовательно получать последнюю цифру числа и сравнивать её с
    соседней цифрой.
4.  Если найдены разные цифры, вернуть `false`.
5.  Если все сравнения пройдены, вернуть `true`.

## Задача 3.8. Левый треугольник

### Текст задачи

Реализовать метод `leftTriangle(int x)`, который выводит треугольник из
символов `*` высотой `x`. В каждой следующей строке количество символов
увеличивается на один.

### Алгоритм решения

Использовать два вложенных цикла. Внешний цикл отвечает за номер строки
от 1 до `x`. Внутренний цикл печатает столько символов `*`, каков номер
текущей строки. После каждой строки выполняется переход на новую строку.

## Задача 3.10. Угадайка

### Текст задачи

Реализовать метод `guessGame()`, который загадывает случайное число от 0
до 9, принимает числа пользователя до правильного ответа и выводит
количество попыток.

### Алгоритм решения

1.  С помощью `Random` сгенерировать число от 0 до 9.
2.  Установить счётчик попыток в 0.
3.  В цикле считывать число пользователя.
4.  После каждого ввода увеличивать счётчик попыток.
5.  Если введённое число совпало с загаданным, вывести сообщение об
    успехе и количество попыток, затем завершить цикл.
6.  Если числа не совпали, сообщить об ошибке и продолжить игру.

# Задание 4

## Задача 4.2. Поиск последнего значения

### Текст задачи

Реализовать метод `findLast(int[] arr, int x)`, который возвращает
индекс последнего вхождения числа `x` в массив. Если число отсутствует,
вернуть `-1`.

### Алгоритм решения

Пройти по массиву циклом от первого элемента до последнего. При каждом
совпадении сохранять текущий индекс. После завершения цикла проверить,
было ли найдено совпадение. Если нет --- вернуть `-1`, иначе вернуть
последний сохранённый индекс.

## Задача 4.4. Добавление в массив

### Текст задачи

Реализовать метод `add(int[] arr, int x, int pos)`, который возвращает
новый массив со всеми элементами исходного массива и вставляет значение
`x` в позицию `pos`.

### Алгоритм решения

1.  Проверить, что позиция находится в допустимом диапазоне от 0 до
    длины массива включительно.
2.  Создать новый массив длиной на один элемент больше исходного.
3.  Скопировать элементы исходного массива до позиции вставки без
    изменения индексов.
4.  В позицию `pos` записать значение `x`.
5.  Элементы, расположенные после позиции вставки, скопировать со
    сдвигом на одну позицию вправо.
6.  Вернуть новый массив.

## Задача 4.6. Реверс

### Текст задачи

Реализовать метод `reverse(int[] arr)`, который изменяет исходный массив
так, чтобы его элементы располагались в обратном порядке.

### Алгоритм решения

Организовать цикл до середины массива. На каждой итерации поменять
местами элемент с начала массива и симметричный ему элемент с конца. Для
обмена использовать временную переменную. После завершения цикла массив
будет перевёрнут.

## Задача 4.8. Объединение

### Текст задачи

Реализовать метод `concat(int[] arr1, int[] arr2)`, который возвращает
новый массив: сначала элементы первого массива, затем элементы второго.

### Алгоритм решения

1.  Создать новый массив длиной, равной сумме длин двух исходных
    массивов.
2.  Скопировать в него все элементы первого массива.
3.  Продолжить заполнение с позиции после последнего элемента первого
    массива, добавив элементы второго массива.
4.  Вернуть новый массив.

## Задача 4.10. Удалить негатив

### Текст задачи

Реализовать метод `deleteNegative(int[] arr)`, который возвращает новый
массив, содержащий все элементы исходного массива, кроме отрицательных.

### Алгоритм решения

1.  Первым проходом по массиву посчитать количество неотрицательных
    элементов.
2.  Создать новый массив нужного размера.
3.  Вторым проходом скопировать в новый массив все элементы, которые
    больше или равны нулю.
4.  Вернуть новый массив.
